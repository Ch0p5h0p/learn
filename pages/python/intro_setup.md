# Python Introduction and Setup

Welcome to Python! This will be your first step into programming. Before we start with coding, let's get set up.

## IDE
Firstly, you'll want something called an IDE, or an Integrated Development Environment. This is the place we'll write our code. There are MANY options out there, so I'll give you my personal recommendations:

### PyCharm
PyCharm is an IDE by JetBrains, and is a very strong Python IDE. If for some reason I don't feel like just using my terminal, I like PyCharm. I find it very friendly.

### VS Code
My first ever IDE. It's developed by Microsoft and has a very rich plugin ecosystem. Unlike PyCharm, it supports all programming languages through use of its extensions (plugins). If you don't want to get tangled with Microsoft, there's a fork of VS Code called VS Codium, and it's fully open source.

### Your teminal!
If you have any form of experience with your terminal, my method of choice for coding Python is simply installing Python and writing my code in NeoVim or another text editor. Look up online how to install Python for your operating system. It most likely exists for it. I'm not familiar with Windows, but on MacOS and Linux, you simply have to install Python, then in your terminal run `python myScript.py` and it will execute the Python code contained in `myScript.py`.

### The internet!
Surely you can find an online python IDE to test your code if you for some reason can't install Python on your computer. [GitHub.dev](https://github.dev) is one I used on my old ChromeBook. You do need a GitHub account though (which is free), which is a good thing to have if you plan to use coding often.

## Files
Python files should always have the extension `.py` after their name. This signifies that the file is a Python file. Outside of that and the general conventions of naming files (alphanumeric as well as _, -, and a few other symbols are allowed to be used in file names), there are no other restrictions.

## About Python
*This isn't entirely necessary to understand as of now, so you can skip this, but I think it's nice to know a little about the language you're learning.*

Python is what's known as an *interpreted language*. Basically, these are languages where the source code (our `.py` file) is turned immediately into execution instead of becoming an executable file, such as a `.exe` file. I'm not a history fanatic, so I can't recite the whole history of Python off the top of my head, but [this Wikipedia article](https://en.wikipedia.org/wiki/Python_(programming_language)) does a pretty good job of explaining it, I think.
